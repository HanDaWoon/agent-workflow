- 결과: <바뀐 행동 또는 해결한 결정>
- 작업 commit: <실제 SHA 또는 미커밋>

| 검사 | 결과·증거 | 한계 |
| --- | --- | --- |
| <명령 또는 CI job> | <통과/실패/미실행 및 로그> | <해당 없으면 없음> |

- 리뷰: <자기/독립 검토, 기준·대상 commit, Spec/Standards 결과와 미해결 항목>
- 리뷰 범위: <전체 저장소/커밋 범위/고정된 작업 상태; 미커밋·미추적 파일 포함 여부>
- 통합: <미통합/통합됨/해당 없음; 목표 branch·commit·PR 근거>
- 배포: <미배포/배포됨/해당 없음; 필요한 경우 환경·배포 근거>
- 이슈: <열림/종료/미발행; 종료 조건 충족 여부>
- 자원 정리: <종료한 터미널·제거한 워크트리와 실제 목록/경로 확인; 보존한 검증 자료 위치>
- 남긴 자원: <없음 또는 자원별 소유자·보존 이유·정리 가능해지는 조건; 미확인 정리는 미완료로 표시>
- 남은 작업·blocker: <없음 또는 구체적 미완료 항목과 다음 책임>

실행에 모델 선택이 포함됐다면 `에이전트 호스트 / 역할 / 선택 이유 / 요청 model·effort / 적용 model·effort / 확인 근거`를 추가한다. 감독 실행이면 실제 Task/Dispatch·워크트리 연결을 덧붙인다. 지원하지 않는 제어는 해당 없음, 실제 적용을 확인하지 못한 값은 미확인으로 표시한다.
