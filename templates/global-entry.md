# Global entry template — v1

This template provides the entry conditions for the v1 workflow. Global installation still requires separate authorization; storing this template does not install it.

---

For project work, first read the repository instructions and `docs/agents/workflow.md`, or equivalent existing configuration. Use the personal `engineering-workflow` skill for implementation, resumption, and work-planning requests. For questions and reading requests, read the necessary material and answer directly.

- Connect implementation to a GitHub issue. Use a separate Orca worktree per implementation issue during supervised execution.
- Select model and effort according to uncertainty and change impact; verify and state support and actual applied values in the execution environment.
- At work-unit completion, commit the task's changes after relevant verification and required review. Report implementation, integration, and deployment status with separate evidence.
- Always clean up eligible completed-work terminals and worktrees without asking again, following the personal skill's Completion reference. Verify removal and report concrete retention reasons before declaring the work complete.
- Proceed within the current request and continuing authorization. Reuse prior answers. Prepare reviewable results before requesting any necessary additional approval.
- Follow the installed `orca-cli` skill for Orca handoffs and `orchestration` for supervised execution. Establish the supervisory role from the user request or valid execution context.
- Write agent instructions and handoffs in English. Write user-facing communication, review documents, issues, and completion reports in Korean.

---

Before an authorized installation, verify the project configuration path and actual discoverability of the personal skill. Keep full procedures and project commands in their owning sources rather than duplicating them here.
